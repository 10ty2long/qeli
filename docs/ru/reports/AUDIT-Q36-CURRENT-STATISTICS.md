Оба stock server/client работают в отдельных network и private mount namespaces одной VM .10 с двумя vCPU, affinity 0–1/nice0. TUN MTU1400, carrier MTU1500; defaults очередей не менялись. CLI SHA `52511cebd43aca364e317c04955287630dc24055de32168206d280ddbee82069`: фактическая квалифицированная fat-LTO/codegen1/jemalloc сборка. 916 входов проверены; отличие buffer_pool — два ранее проверенных изменения форматирования. В assets.rs изменён только cfg(test), CSS панели обновлён, web выключен в этих сессиях. Не заявляется байтовое совпадение с новым бинарником после изменений панели. Новая пересборка не выполнялась.

Второй проход меняет порядок режимов и фаз. Каждое условие имеет три независимые сессии; raw JSON и все 72 worker logs сохранены. Без strace, BPF или изменения product defaults. CPU/RSS снимаются прежней квалифицированной обвязкой, без утверждения о нулевой стоимости наблюдения.
