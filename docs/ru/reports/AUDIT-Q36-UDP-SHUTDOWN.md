# Q36-F018: остановка UDP и сохранение ошибок задач

<!-- normative-sync: q36-udp-shutdown-v2 -->

11 октября 2026. База: `2c5fcd5e`. Статус: **исправлено в исходниках;
регрессии и функциональный native AUTH PASS; штатный release AUTH/rate OPEN**. Q36 остаётся IN_PROGRESS.

Во время расширения AUTH-матрицы штатный SIGTERM частного UDP-сервера вернул
exit 1: `UDP receive pump stopped`. При остановке `ProfileTasks` сначала отменяет
дочерний приёмник. Его канал может закрыться раньше, чем отмена дойдёт до listener.
Прежний обработчик считал любое закрытие канала аварией.

Приёмник теперь различает остановку владельца и неожиданную потерю канала в
работающем поколении профиля. Supervisor также допускает нормальное завершение
UDP-worker при остановке. Сбор всех остальных workers перенесён в общий
`supervise_udp_workers`: отмена ожидаема, завершённые ошибки и паники сохраняются
в существующем ограниченном накопителе. Пустой набор и нормальный выход в живом
профиле остаются ошибками. INI, ABI и wire format не меняются.

## Проверки и доказательства

- Два отрицательных контроля используют точные прежние ветви исходников:
  тест штатной отмены receive pump падает; два теста остановки/сбора workers
  также падают. Адаптеры меняют только окружение вызова.
- 38 тестов точного исходного кода проходят на Windows (Rust 1.98.0) и Linux
  `.10` (Rust 1.97.0). Небольшой crate содержит полные модули tasks/shutdown,
  точные функции ожидания/receive pump и их тесты. Это не вся библиотека Qeli.
  Шесть регрессий охватывают отмену, живой профиль, ошибки/паники и пустой набор.
- 77 тестов инструментов benchmark проходят на каждой ОС. Проверены границы
  инструментирования реального native client, proof/AuthOK, PID, режимы и SUN_LEN.
  Приватная инструментированная копия клиента останавливается до NetworkPlan.
- Linux-каталог с результатами архивирован, SHA проверен перед удалением.
  Работающая служба `.10`, её PID и SHA бинарника сохранились.
- Полная сверка `.10` **FAIL**: между снимками добавлены два FORWARD-правила
  для vpn0 и MASQUERADE для 10.8.0.0/24 через ens18. Эти ранее наблюдавшиеся
  правила не скрыты нормализацией и не удалены. Проверки не меняли firewall.

[Машиночитаемые доказательства](../../../release/audit_q36_udp_shutdown_2026-10-11.json)
содержат SHA исходников, логов, архива, обе проверки прежнего кода и полные

## Функциональный native AUTH — 11 октября 2026

Приняты 756 клиентов; проверены proof закреплённого ключа, настоящий AuthOK
и уникальные IP в реестре. Все 108 частных серверов и 756 клиентов завершились
с exit 0. Старые 23 серии не использованы.

Оба CLI собраны из текущих 916 исходных файлов; частные examples включают
настоящий main.rs. Клиент инструментирован только для барьера AUTH и выхода

в частной копии выбран rlib и lto=false вместо fat LTO, codegen-units=16; оптимизация=3,
panic=abort и strip сохранены. Это **не штатный release-бенчмарк**:
показатели скорости/ёмкости этой сборки не публикуются в benchmark_results.
При lto=false Cargo допускает локальный thin LTO между codegen units.
Матрица подтверждает интеграцию исправления F018 в этих условиях,
но не заменяет измерения скорости штатного release.
